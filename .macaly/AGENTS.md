## Project Context
App: Mariančina jazyková dobrodružství — Czech spelling learning app for a 9-year-old (3rd grade).
Language: Czech UI, all content in Czech.
Stack: Next.js + Tailwind CSS, no database (localStorage for progress).

## Design Tokens
- Primary font headings: Baloo 2 (`font-baloo`)
- Body font: Nunito (`font-nunito`)
- Primary color: violet (`--violet: 243 57% 66%` → #7F77DD)
- Accent color: gold (`--gold: 37 86% 55%` → #EF9F27)
- Success: green (`--success: 142 72% 45%`)
- Error: red (`--error: 4 90% 58%`)
- Background: white with violet/amber gradient

## Testing Preferences
Careful: check work after every non-trivial change, fewer bugs.
